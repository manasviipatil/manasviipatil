## 🔍 CampusVoice — Project Overview

CampusVoice aims to make student feedback more organized, accessible, and actionable.

### ✨ Core Features

- 📝 **Feedback Submission:** Share suggestions, complaints, and improvement ideas.
- 🕶️ **Anonymous Feedback:** Submit feedback without displaying personal identity.
- 🗂️ **Categorization:** Organize submissions by campus-related categories.
- 🚦 **Priority Management:** Classify concerns according to their priority.
- 🔄 **Status Tracking:** Follow the progress of submitted feedback.
- 👍 **Community Voting:** Upvote submissions to highlight important concerns.
- 📊 **Dashboard:** Present feedback activity and campus improvement information.
- ✏️ **Submission Management:** Support relevant actions on personal submissions.

### 🛠️ Technology Stack
